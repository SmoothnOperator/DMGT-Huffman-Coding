⚔️ Direct Head-to-Head Race: Huffman (Bottom-Up) vs. Shannon-Fano (Top-Down) 🏆 Huffman Provably Optimal

While both algorithms construct prefix-free binary trees, Shannon-Fano is a top-down greedy heuristic that partitions frequencies into equal halves, which can lock the tree into suboptimal splits. Huffman is bottom-up, proven mathematically by David Huffman in 1952 to achieve minimum expected length: \( L(C)_{Huffman} \le L(C)_{SF} \).
